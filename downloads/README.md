# TikSave ⚡ - TikTok Video Downloader

A modern, SaaS-style web application to download TikTok videos in high quality. Built with FastAPI and vanilla JavaScript.

## Features
- 🚀 Fast asynchronous backend processing
- 🎨 Beautiful UI with Dark/Light mode toggle
- 🛡️ Auto-cleanup of old files to save server space
- 🔒 Secure URL validation

## How to Run Locally

1. **Install Python** (3.8+ recommended)
2. **Clone/Download** this repository.
3. **Open Terminal** in the project folder.
4. **Install Requirements:**
   ```bash
   pip install -r requirements.txt
